Prayer Walk Privacy Policy

Last updated: 2026-05-17

Prayer Walk is built to be private by default. This policy explains what we collect, what we don't, and what you control.

What we collect

Location data: While you have an active prayer walk recording in progress, the app reads your device's GPS coordinates to draw your route. Location collection stops the moment you press Stop. The app does not request or use background location permission.

Where it's stored

All recorded walks, including GPS coordinates and timestamps, are stored locally on your device only using AsyncStorage. We do not operate any server. Your walks are never transmitted to us, never uploaded to a cloud, and never shared with any third party.

What we don't do

  • No accounts, no logins, no user IDs
  • No analytics, no telemetry, no crash reporting
  • No advertising, no ad networks, no tracking SDKs
  • No background location collection
  • No data sharing or selling — there is no data to share or sell

Sharing your data (your choice)

The app provides explicit, user-initiated sharing controls:

  • Share Walk: Generates a text summary of one walk that you can send to others via the native share sheet.
  • Export GPX: Saves a single walk as a GPX file you can import into other apps (Strava, Garmin Connect, etc.).
  • Backup JSON: Saves your full walk history as a JSON file on your device. You control where this file goes.
  • Restore from Backup: Imports a previously exported JSON file back into the app.

These features only run when you tap them. Nothing is shared automatically.

Permissions we request

  • ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION (Android) and NSLocationWhenInUseUsageDescription (iOS) — used only while a walk is actively recording.

Children's privacy

The app does not knowingly collect personal information from anyone, including children under 13. If a child uses the app, the same local-only model applies.

Changes to this policy

If this policy ever changes meaningfully, the updated date at the top of this page will reflect the change, and a note will appear in the app's release notes.
